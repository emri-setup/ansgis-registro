# ansgis · registro

Quienes existen y que se puede instalar. **Es una lista, nada mas** — igual que el
`packages.json` de r-universe.

- `agentes.json` — los agentes registrados y las obras que produjeron
- `plantillas/` — el catalogo: lo que un municipio puede traerse a su zona

## El porton

Todo cambio pasa por un pull request, y **ninguna capacidad declarada entra si el
diccionario no la respalda**. La verificacion corre desde
[`ansgis-maquinaria`](https://github.com/emri-setup/ansgis-maquinaria) `@v1`.

Es el equivalente de `R CMD check`: alla un paquete que no compila no llega al
estante; aca un agente que declara algo que nadie respalda no llega a nacer.
